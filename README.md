# Java Sales & Inventory System API 🛒

API em Java desenvolvida para gerenciar operações de vendas em tempo real, realizando validações rígidas de estoque e processamento seguro de transações financeiras.

## 🚀 Funcionalidades
- **Validação de Estoque**: Sistema automatizado que verifica a disponibilidade de itens antes de aprovar qualquer transação, impedindo vendas inválidas.
- **Processamento de Pagamentos**: Lógica integrada para aplicação de descontos dinâmicos baseados no método de pagamento escolhido (ex: 10% de desconto automático para transações via PIX).
- **Atualização Automática**: Baixa imediata na quantidade de produtos do estoque após a confirmação da venda.

## 🛠️ Tecnologias Utilizadas
- Java SE (Standard Edition)
- Estruturas de Controle de Fluxo e Condicionais Avançadas (`if/else` aninhados)
- Manipulação e Comparação de Strings (`.equals()`)

## 📈 Impacto de Negócio
Este projeto simula com alta fidelidade as regras de negócio cruciais de sistemas transacionais e de e-commerce utilizados por grandes instituições financeiras e redes de varejo. O foco principal é garantir a consistência dos dados, a segurança das validações e a automação do fluxo de caixa operacional.
